    TRM-02 · 컴포넌트
  1. 1타입 코드 — 시스템에서 약관을 구분하는 값(type). 단일 입력란이며 저장 후에는 수정 불가. 중복 검증은 이 입력란에서 실시간으로 처리함(별도 확인 입력란 없음).
  2. ·입력 규칙 — 영문·숫자·특수기호 입력 가능 · 한글 입력 불가 · 공백은 제거됨. 하단에는 안내 문구 및 예시가 노출됨.

  4. 3본문 — 약관 내용(contents)을 인라인 에디터로 입력. 저장 포맷은 마크다운.
  5. 4취소 / 저장 — 저장 클릭 시점에 서버로 전송하고, 그 결과에 따라 토스트를 노출함. 성공 시 해당 타입의 v1이 생성되고 목록으로 이동하며 초록 토스트 [toast] "약관 저장이 완료되었습니다.", 필수값이 비어 있으면 빨간 토스트 [toast] "타입 코드 · 약관명 · 본문을 모두 입력해 주세요." 노출 후 저장 중단. 취소 시 입력값을 폐기하고 목록으로 복귀.

닫기
    TRM-03 · 컴포넌트
  1. 1대표 타이틀 · 요약 정보 — 타이틀은 변경되는 약관명이 아니라 불변값인 타입 코드. 타입 코드 오른쪽에 현재 버전 · 등록일을 요약 표기함. 화면 상단 좌측 뒤로가기 버튼으로 목록 복귀(어드민 공통 헤더).
  2. 2수정 — 상세는 진입 시 읽기 전용이며, 이 버튼을 눌러야 편집 모드로 전환됨.
  3. 3약관명 — 읽기 전용으로 현재 버전의 title 표시.
  4. 4본문 — 읽기 전용으로 현재 버전의 contents 표시.
  5. 5버전 이력 섹션 — 섹션 헤더에 총 N개를 표기함.
  6. 6이력 목록 — 버전(현재 버전에 현재 배지) · 약관명 · 생성일시(createdAt) · 작성자 · 보기. 최신순 정렬이며 페이지네이션 없이 전체 이력을 누적 노출함.
  7. 7수정 모드 — 빈 입력창이 아니라 현재 약관명·본문을 그대로 불러온 상태에서 편집함. 편집 항목은 약관명·본문 2가지. 취소 시 편집 내용을 버리고 읽기 전용으로 복귀, 저장 시 버전을 1 올려 그 버전으로 기록·저장한 뒤 목록으로 이동하며 [toast] "약관 저장이 완료되었습니다." 노출.
  8. 8이전 버전 보기(읽기 전용 모달) — 이력의 보기 클릭 시 상세 화면 위에 dimmed 배경과 함께 모달로 노출. 타입 코드 · 약관명 · 생성일시(작성자) · 본문 원문을 읽기 전용으로 표시하며, 닫기 또는 × 로 상세 화면 복귀.
  9. ·케이스 · 변경 없이 저장 — 약관명·본문을 그대로 둔 채 저장 클릭 시.
    처리 — 저장 클릭 시점에 빨간 토스트 [toast] "변경된 내용이 없습니다." 노출 후 저장 중단. 신규 버전을 만들지 않고 편집 상태를 그대로 유지함.
  10. ·케이스 · 필수값 미입력 저장 — 약관명 또는 본문을 비운 채 저장 클릭 시.
    처리 — 저장 클릭 시점에 빨간 토스트 [toast] "약관명과 본문을 입력해 주세요." 노출 후 저장 중단. 입력값은 그대로 유지되어 이어서 작성 가능.
  11. ·노출 반영 — 저장된 현재 버전이 서비스 노출 대상이 됨. 노출 상태(status)는 서버가 현재 버전 기준으로 자동 관리함.

  3. 3에러 토스트(빨강) — 필수값을 채우지 않고 저장하면 빨간 토스트로 타입 · 약관명 · 본문을 모두 입력해 주세요. 를 노출함(상세 수정은 약관명과 본문을 입력해 주세요.). 저장은 중단되고 입력값은 유지됨.
  4. 4저장 완료 토스트(초록) — 저장 버튼 클릭 후 서버 저장이 완료된 시점에 노출됨. 등록·수정 저장이 완료되면 초록 토스트 [toast] "약관 저장이 완료되었습니다." 노출 후 목록으로 이동함. 등록은 v1, 수정은 신규 버전이 생성된 뒤 노출됨.
  5. ·버전 1개(v1) — 상세 하단 이력에 1건만 표시(최신 배지 · 이전 버전 없음).
