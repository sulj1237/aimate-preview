1AI mate 추천 상품이란?

환자의 처방 약물을 바탕으로, 그 약을 오래 복용할 때 부족해질 수 있는 영양소와 이를 보충할 추천 상품을 함께 보여주는 상담 참고 기능입니다.

  • 치료·예방을 단정하는 정보가 아니라, 상담을 돕는 참고 정보입니다.
  • 영양소별로 우리약국 추천 상품과 굿팜 추천 상품을 함께 제시합니다.

2POS에서 추천 상품 확인하기

처방 상세 분석 화면에서 처방 약물표 바로 아래에 추천 영역이 자동으로 표시됩니다.

🖼️
예시 화면 · POS 추천 영역
처방 약물표 하단 · 영양소별 블록(좌: 영양소·이유 / 우: 추천 상품)

화면 구성 (영양소별 블록)

  • 왼쪽 — 부족해질 수 있는 영양소명 · 부족해지는 이유(상담 참고 설명) · ⓘ(근거·참고문헌)
  • 오른쪽 — 우리약국 추천 상품 / 굿팜 추천 상품
  • 어떤 관련 처방 성분 때문에 부족해지는지도 참고로 표시됩니다.
부족해지는 이유는 화면에 보이는 설명 문구이고, 근거·참고문헌은 그 설명의 출처로 ⓘ 아이콘에서 확인하는 보조 정보입니다.
POS AI mate에서는 추천 정보를 조회만 할 수 있습니다. 우리약국 추천 상품 수정은 약사웹에서만 가능하며, 굿팜 추천 상품은 굿팜 운영자가 관리합니다.

3추천 상품이 표시되는 기준

  • 처방약에 매칭된 영양소별로, 우리약국 또는 굿팜 추천 상품이 1개 이상 있으면 그 영양소 블록이 표시됩니다.
  • 우리약국·굿팜 추천 상품이 모두 없으면 그 영양소 블록은 표시되지 않습니다(별도 문구 없음).
  • 추천 정보를 불러오지 못한 경우(오류)에만 “추천 정보를 불러오지 못했습니다.”와 재시도 안내가 표시됩니다.

4우리약국 추천 상품 설정하기

약사 어드민웹의 AI mate 추천 상품에서 영양소별로 우리약국 추천 상품을 설정합니다.

🖼️
예시 화면 · 약사웹 추천 상품 설정(상세)
우리약국 추천 상품 등록/정렬/삭제 · 굿팜 추천 상품 조회
  1. 영양소 선택목록에서 설정할 영양소 행을 클릭해 상세로 들어갑니다.
  2. 추천 상품 설정[＋ 우리약국 추천 상품 추가] 버튼으로 상품 추가 화면으로 이동합니다. 상품 추가 방식은 추후 확정된 화면 기준으로 별도 안내합니다.
  3. 순서·삭제등록한 상품은 순서 조정·삭제할 수 있고, 우측 하단 [저장]으로 반영합니다.

우리약국 추천 vs 굿팜 추천

구분설정 주체POS 표시
우리약국 추천 상품약국(약사웹에서 직접)굿팜 추천보다 우선 표시
굿팜 추천 상품굿팜 운영자(슈퍼어드민)기본 추천으로 표시
  • 우리약국 추천 상품은 영양소별 최대 3개까지 등록합니다.
  • 굿팜 추천 상품은 약사웹에서 조회만 가능합니다(수정 불가).

5AI mate 노출 중지 상태란?

굿팜에서 특정 영양소를 노출 중지(OFF) 하면 POS에는 표시되지 않지만, 데이터가 사라지는 것은 아닙니다.

  • 약사웹 목록에서는 숨기지 않고 “AI mate 노출 중지” 상태로 표시됩니다.
  • OFF 상태에서도 우리약국 추천 상품을 등록·수정·삭제할 수 있습니다(미리 준비 가능).
  • 저장한 값은 POS에 바로 표시되지는 않고, 굿팜이 다시 ON으로 변경하면 그대로 POS에 반영됩니다.

6추천 상품이 안 보이는 경우

상황이유
우리약국·굿팜 추천 상품이 모두 없음표시할 상품이 없어 블록 미표시(정상)
굿팜이 해당 영양소를 노출 중지(OFF)POS 미표시(약사웹에는 ‘노출 중지’로 표시)
처방약에 매칭되는 데이터가 없음부족 영양소가 조회되지 않아 미표시
추천 API 오류“추천 정보를 불러오지 못했습니다.” + 재시도 안내
성분 또는 영양소가 삭제 처리됨해당 항목 미표시

7자주 묻는 질문

우리약국 추천 상품과 굿팜 추천 상품은 뭐가 다른가요?
우리약국 추천 상품은 약국이 약사웹에서 직접 설정하고 POS에서 먼저 표시됩니다. 굿팜 추천 상품은 굿팜 운영자가 관리하는 기본 추천입니다.
AI mate 노출 중지 상태인데 상품을 설정할 수 있나요?
네. OFF 상태에서도 우리약국 추천 상품을 미리 등록·수정할 수 있고, 다시 ON이 되면 저장한 값이 그대로 표시됩니다.
POS에서 추천 상품을 바로 수정할 수 있나요?
POS는 조회 전용입니다. 우리약국 추천 상품 수정은 약사웹에서 하시면 됩니다.
어떤 처방에는 추천이 안 뜨는데 오류인가요?
추천 상품이 없거나 매칭 데이터가 없으면 정상적으로 표시되지 않습니다. 오류일 때만 안내 문구와 재시도가 나타납니다.
PART B · 굿팜 운영자용
굿팜 운영자용 안내서
대상: 슈퍼어드민 운영자 — 영양소·성분·이유/근거·굿팜 추천 상품·노출·삭제 운영

1AI mate 추천 상품 운영 구조

운영은 두 관리 화면으로 나뉩니다.

화면기준여기서 관리하는 것
영양소 관리부족 영양소관련 카테고리 · 굿팜 추천 상품(최대 2) · 노출 ON/OFF · 관련 성분(조회) · 삭제
성분 관리성분코드성분명(공통값) · 부족해지는 이유·근거(영양소별) · 부족 영양소 연결
🖼️
예시 화면 · 영양소 관리 목록 / 성분 관리 목록
메뉴: AI Mate 추천 상품 관리 > 영양소 관리 · 성분 관리

등록 순서

  1. 영양소 관리 > ＋ 영양소 추가부족 영양소를 먼저 등록합니다(기본 노출 OFF).
  2. 성분 관리 > ＋ 성분 추가성분코드·성분명을 등록하고, 앞서 만든 부족 영양소를 연동해 이유·근거를 입력합니다.
  3. 노출 ON검토 후 영양소 관리에서 노출을 켜면 POS에 반영됩니다.

2데이터 매칭 기준

  • 처방약 성분코드와 데이터의 성분코드가 완전히 일치할 때만 매칭됩니다.
  • 성분은 약물의 주성분명(예: metformin)이고, 성분코드는 함량·제형 차이까지 구분하는 상세 식별 코드입니다.
  • 실제 매칭·수정·삭제 기준은 성분코드 단위입니다.
  • 주성분 단위로 묶어 보여주는 방식은 목록 탐색·표시 편의를 위한 보조 기준입니다(적용 여부는 확정 필요).
성분명이 같아도 성분코드가 다르면 함량·제형이 다른 별개 항목으로 관리됩니다.

3영양소 관리

부족 영양소 단위로 관리하는 화면입니다.

  • 관련 카테고리 · 굿팜 추천 상품(최대 2) · 노출 ON/OFF를 여기서 설정합니다.
  • 관련 성분은 이 영양소에 연결된 성분코드 목록으로, 조회합니다(행을 클릭하면 성분 관리로 이동해 수정).
  • [＋ 영양소 추가]로 부족 영양소를 등록하면 기본 노출 OFF로 시작합니다.
🖼️
예시 화면 · 영양소 관리 상세
노출 토글 · 관련 카테고리 · 굿팜 추천 상품(최대 2) · 관련 성분(조회)

4성분 관리

성분코드 단위로 성분명과 이유·근거를 관리합니다.

  • 성분명은 성분코드 기준 공통값이라, 한 번 수정하면 그 성분과 연결된 모든 영양소·화면에 함께 반영됩니다.
  • 부족해지는 이유와 근거·참고문헌은 (성분코드 × 영양소) 조합별로 독립입니다. 같은 성분이어도 영양소가 다르면 따로 관리됩니다.
  • 연결된 부족 영양소는 조합별로 추가·삭제할 수 있습니다(추가 시 전체 영양소에서 검색·선택).
🖼️
예시 화면 · 성분 관리 상세
성분명(공통값) 수정 · 연결 부족 영양소별 이유·근거 · 부족 영양소 연결 추가(검색)

5부족 영양소·성분 등록

버튼위치내용
＋ 영양소 추가영양소 관리부족 영양소·관련 카테고리 등록 → 기본 노출 OFF
＋ 성분 추가성분 관리성분코드·성분명 + 기존 부족 영양소 연동 + 부족해지는 이유·근거
성분 추가 시 입력한 성분코드와 앞부분이 같은 기존 성분코드가 있으면 참고용으로 보여줍니다(자동 복사·병합은 하지 않음 · 이 기능은 개발 확인 필요).
🖼️
예시 화면 · 영양소 추가 / 성분 추가 모달
＋ 영양소 추가(부족 영양소 등록) · ＋ 성분 추가(성분코드·성분명 + 부족 영양소 연동)

6OFF와 삭제 기준

OFF(노출 중지)삭제
성격일시적인 POS 노출 중지전 서비스 미노출 처리
데이터보존(약사웹 편집 유지)원천 데이터·삭제 이력 보존
복구다시 ON 하면 그대로 표시미노출 처리(신중히 사용)
일시적으로 추천에서 제외하려면 삭제가 아니라 OFF를 사용하세요.

성분 삭제 시 영향 범위

  • 해당 성분코드 기준의 추천·부족해지는 이유·근거가 슈퍼어드민 · 약사웹 · POS 모두에서 미노출됩니다.
  • 삭제 이력과 원천 데이터는 보존됩니다.

7결측 데이터 처리

  • 부족해지는 이유·근거가 비어 있어도, 추천 상품이 있으면 POS 블록은 노출하고 없는 항목만 생략합니다(이유 없음→문구 생략, 근거 없음→ⓘ 생략, 카테고리 없음→배지 생략).
  • 추천 상품이 없을 때만 블록을 표시하지 않습니다.
  • 관리 화면에서는 미등록 항목을 “데이터 없음”으로 표시합니다.
