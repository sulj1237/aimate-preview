## 6. 미확보 2종의 수급 계획

### 6.1 안전성 사용중지·회수 정보 — **API로 받는다**

공공 API가 있으므로 크롤링하지 않는다. 이용 조건이 명확하고, 항목 구조가 바뀌어도 공지가 따른다.

| 단계 | 내용 | 담당 |
|---|---|---|
| 1 | [식약처 의약품 회수·판매중지 정보](https://www.data.go.kr/data/15059114/openapi.do) 개발계정 신청 (활용목적 문안은 작성해 둠) | 개발 |
| 2 | 응답 필드 확인 — 품목기준코드 · 제품명 · 제조번호 · 회수 사유 · 적용일 · 해제 여부 | 개발 |
| 3 | **일 1회 조회**해 내부 저장소에 적재 (변경분만) | 개발 |
| 4 | 품목기준코드로 약품 마스터와 연결 → 약품 상세·처방 카드에 안전성 알림 | 개발 |
| 5 | 회수와 전체 사용중지를 구분해 문구를 다르게 둔다 | 기획 |

| 항목 | 정한 것 |
|---|---|
| 갱신 주기 | 일 1회 (수시 공지되는 자료) |
| 저장 | 내부 저장소. 단말에는 두지 않는다 |
| 보조 확인 | [의약품안전나라](https://nedrug.mfds.go.kr/) 공지 — 사람이 확인하는 용도 |

**크롤링은 대안으로만 둔다.** API가 신청 거절되거나 항목이 부족할 때에 한해 검토하고, 그때도 대상 사이트의 이용 조건을 먼저 확인한다.

### 6.2 점검 기준 지침 — **문서를 받아 규칙으로 옮긴다**

이건 조회해서 쓰는 데이터가 아니라 **읽고 우리 판정 규칙에 반영하는 문서**다. 자동 수집 대상이 아니다.

| 단계 | 내용 | 담당 |
|---|---|---|
| 1 | 「의약품정보의 확인 및 정보시스템 운영 등에 관한 지침」 **현행 전문과 신구조문 대비표** 내려받기 — [보건복지부 훈령·예규·고시·지침](https://www.mohw.go.kr/board.es?mid=a10409020000&bid=0026) · 대한병원협회 등 단체 공지 | 개발 · 기획 |
| 2 | 개정 안내 확인 — 요양기관업무포털 `biz.hira.or.kr` → 모니터링 → DUR정보 → 공지사항 (요양기관 계정) | 개발 · 한일약국 |
| 3 | 우리 판정에 영향을 주는 조항만 뽑아 표로 정리 — **중복 기간 조건 · 임부금기 예외사유 코드 · 염·복합제 동일성분 처리** | 기획 |
| 4 | 그 표를 `03` 판정 규칙·`09` 답변 정책과 대조해 어긋나는 곳을 고친다 | 기획 |
| 5 | 개정 공지를 **분기 1회 확인**하고, 바뀌면 3~4를 다시 한다 | 기획 |

| 항목 | 정한 것 |
|---|---|
| 형식 | HWP·PDF 문서 (데이터 아님) |
| 갱신 | 개정 시. 분기 1회 확인 |
| 보관 | 포털 `refference-doc/`에 원문과 정리표를 함께 둔다 |

**왜 필요한가** — 결과를 받지 못해도 **알림 기준은 맞춰야 한다.** 예를 들어 중복 기간 조건을 모르면 약국에서 뜨지 않는 경고가 고객앱에서 떠 문의로 이어진다.
