## 1. 이 문서가 정하는 것

**화면에 나갈 답을 만들려면 어떤 데이터가 있어야 하는지**를 답 쪽에서 거꾸로 짚는다.
데이터마다 **출처 · 연결 Key · 갱신 주기 · 쓰는 곳 · MVP 여부 · 법무·계약 확인**을 함께 적는다.

데이터의 성격은 네 갈래다. 섞어 쓰면 출처와 판정 근거가 뒤섞인다.

| 갈래 | 하는 일 | 대표 데이터 |
|---|---|---|
| **DUR** | 안전성 판정 | 병용금기 · 임부금기 · 효능군 중복 |
| **Drug Information** | 효능 · 용법 · 주의 · 부작용 설명 | e약은요 · 약학정보원 상세정보 |
| **DIND** | 약물–영양소 관계 (Drug-Induced Nutrient Depletion) | 성분 ↔ 영양소 감소 가능성 · 근거 수준 · 상담 문구 |
| **GoodPharm Context** | 고객·약국 맥락 | 처방 · 구매 · 재고 · 약국 · 위치 |

저장 위치로는 세 층으로 나뉜다. (`16` 3장)

| 층 | 무엇 | 어디에 | 색인 |
|---|---|---|---|
| Personal | 고객의 처방 · 구매 기록 · 판정 결과 | 고객 단말 | 넣지 않는다 |
| Public | 의약품 정보 · DUR 기준 · 굿팜 안내 | 공용 저장소 | 넣는다 (RAG는 MVP 이후) |
| Dynamic | 약국 실재고 | 실재고 기능 | 넣지 않는다 (최신값 조회) |

## 3. 데이터 카드 — 출처 · Key · 갱신 주기

### 3.1 DUR (심평원 점검 기준 · 식약처 공공 API)

심평원 DUR 점검은 **처방전 내**(병용금기 · 특정연령대금기 · 임부금기 · 안전성 사용중지 · 용량주의 · 투여기간주의 · 저함량 배수처방)와
**처방전 간**(병용금기 · 동일성분 중복 · 효능군 중복)으로 나뉜다.

| 데이터 | 쓰는 곳 | 출처 | 연결 Key | 갱신 주기 | MVP | 법무·계약 |
|---|---|---|---|---|---|---|
| **병용금기·병용주의** | 함께 복용 확인 | 식약처 DUR 품목정보 API `getUsjntTabooInfoList` | 성분코드 쌍 · 품목기준코드 쌍 | 고시 개정 시 (연 수회) | **필요** | 고객앱 노출 가능 여부 |

**MVP는 병용금기 · 성분 중복 · 효능군 중복 셋이다.** **추가 고객정보(임신 여부 · 나이 등) 없이 판정이 선다.**
임신 여부와 나이가 있어야 서는 항목은 고객이 그 질문을 고를 때만 다룬다.

### 3.1.1 공식 기준과 화면 표현을 구분한다

| 구분 | 공식 명칭 (데이터·고시) | 화면 표현 | 근거 |
|---|---|---|---|
| 함께 쓰면 안 되는 조합 | **병용금기** (식약처 고시 · DUR 점검 항목) | `병용 주의` — 고객에게 단정하지 않는 UX 표현 | `09` 9.1.2 |
| 같은 성분이 겹침 (공식 점검) | **동일성분 중복** (DUR 처방전 간 점검) | `성분 중복` | 〃 |
| 같은 성분이 겹침 (굿팜 자체) | — (공식 항목 아님) | `성분 중복` | 단말의 처방·구매 성분코드 비교 |

화면 표현이 같아도 **근거가 다르면 출처를 따로 적는다.** 자체 비교는 `내 처방·구매 기록의 성분 비교`, 공식 점검은 `식약처·심평원 DUR 기준`이다.

### 3.4 DIND — 약물–영양소 관계 (Drug-Induced Nutrient Depletion)

특정 의약품을 **장기 또는 반복 복용할 때 비타민·미네랄 등 영양소가 줄어들 수 있다**는 관계를 담은 Knowledge다.
DUR과는 **별도 레이어**로 관리한다. 국가 표준 안전성 DB가 아니라 조합마다 근거 강도가 다르기 때문이다.

| 필드 | 내용 |
|---|---|
| 약물/성분 Key | 성분코드 또는 내부 Ingredient ID |
| 영양소 | 비타민 B12 · CoQ10 · 마그네슘 등 |
| 관계 | depletion · 감소 가능성 |
| 적용 조건 | 장기복용 · 특정 용량 · 특정 환자군 |
| 기전 | 흡수 저하 · 대사 변화 · 배설 증가 |
| 근거수준 | 근거 강도 · 등급 |
| 근거문헌 | 논문 · 가이드라인 · 검토자료 |
| 상담 문구 | 고객용 · 약사용 표현 |
| 검수일 · 버전 | Knowledge 관리 |
| 검수자 | 약사 · 전문가 |

| 항목 | 내용 |
|---|---|
| 쓰는 곳 | 처방 기반 영양소 안내 → 관련 상품 → 재고 (MVP 이후 · `09` 8.4) |
| 출처 | AI mate 영양소 Master + 문헌 검토 |
| 연결 Key | 성분코드 ↔ 영양소ID |
| 갱신 주기 | 근거·검수 갱신 시 |
| MVP | 이후 |
| 확인 | 근거 수준 표기 방식 · 상담 문구 수위 · 검수 주체 (6장 8번) |

근거 강도가 조합마다 달라, 고객 답변에는 **근거 수준과 함께 판단 한계를 붙인다.** 안전성 판정(DUR)과 같은 무게로 보여주지 않는다.
