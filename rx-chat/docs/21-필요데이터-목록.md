## 1. 이 문서가 정하는 것

**화면에 나갈 답을 만들려면 어떤 데이터가 있어야 하는지**를 답 쪽에서 거꾸로 짚는다.
데이터마다 **출처 · 연결 Key · 갱신 주기 · 쓰는 곳 · MVP 여부 · 법무·계약 확인**을 함께 적는다.

데이터는 세 층으로 나뉜다. (`16` 3장)

| 층 | 무엇 | 어디에 | 색인 |
|---|---|---|---|
| Personal | 고객의 처방 · 구매 기록 · 판정 결과 | 고객 단말 | 넣지 않는다 |
| Public | 의약품 정보 · DUR 기준 · 굿팜 안내 | 공용 저장소 | 넣는다 (RAG는 MVP 이후) |
| Dynamic | 약국 실재고 | 실재고 기능 | 넣지 않는다 (최신값 조회) |

## 2. 답 → 데이터 역추적

화면·질문마다 **어떤 데이터로 무엇을 판정하고, 무엇을 근거로 보여주는지**를 한 줄로 잇는다.

| 질문 · 화면 | 필요한 데이터 | 판정 Rule | 답변 근거(출처 표기) | 확보 | 부족한 것 |
|---|---|---|---|---|---|
| 이번 처방에서 달라진 점 (카드) | 단말 처방 이력 · 성분코드 · 제품명 · 함량 · 1회 투여량 · 1일 횟수 · 투약일수 | `03` 5장 — 성분코드 앞 4자리 매칭 후 NEW·CHANGED·CONTINUE·미포함 | `내 처방 기록 · 날짜` | 가상 데이터로 구현 | 실제 처방 상세 값 연동 |
| 새로 추가된 약 | 위와 같음 | NEW 판정 | `내 처방 기록` | 〃 | — |
| 빠진 약이 있나요? | 위 + 투약일수 | 미포함 세부 구분(남음·종료) | `내 처방 기록` | 〃 | — |
| 이 약이 무슨 약인가요? | 의약품 효능 | 없음 (조회) | `식약처 의약품 정보` | e약은요 · 약학정보원 | 이용 범위 확인 |
| 복용 방법 | 이번 처방 용법 + 일반 용법 | 처방 용법 우선 (`09` 9.1.5) | `내 처방 기록` + `식약처 의약품 정보` | 〃 | — |
| 지금 드시는 약끼리 괜찮은지 | 처방·구매 성분코드 · 복합제 구성성분 · DUR 병용금기 · 효능군 코드 | 성분코드 일치 → 중복 / DUR 쌍 일치 → 병용주의 / 효능군 일치 → 효능군 중복 | 중복은 `내 처방·구매 기록의 성분 비교`, 주의는 `식약처·심평원 DUR 기준` | 샘플만 | **복합제 구성성분 · 효능군 코드 · DUR 실데이터** |
| 다른 약과 같이 먹어도 되는지 | 위 + 고른 약의 성분·복합제 구성 | 위와 같음 (고른 약 ↔ 내 약) | 위와 같음 | 샘플만 | 위와 같음 |
| 임신 중에 먹어도 되나요? | DUR 임부금기 · 고객이 입력한 임신 여부 | 성분코드 ↔ 임부금기 등급 | `식약처·심평원 DUR 기준` | 샘플만 | **입력 처리 법무 결론** |
| 아이가 먹어도 되나요? | DUR 특정연령대금기 · 입력한 나이 | 성분코드 ↔ 연령 범위 | 〃 | 샘플만 | 〃 |
| 오래 복용할 때 확인할 점 | 장기복용 판정 · 의약품 주의 | 굿팜 AI 약력관리 기준 | `내 처방 기록` + `식약처 의약품 정보` | 판정 기준 미확인 | **장기복용 기준값** |
| 내 주변 약국 재고 | 약국 정보 · 실재고 수량 · 최종 반영 시각 · 좌표 | 거리 계산 + 재고 보유 여부 | `약국 재고 (기준 시각)` | 굿팜 내부 | **최종 반영 시각 조회 가능 여부** |
| 굿팜 이용 문의 | 굿팜 서비스 안내 | 없음 (조회) | `굿팜 서비스 안내` | 사내 | 근거 자료 위치 |
| 값 확인 화면 (OCR 수정) | 지킴 OCR 판독값 · 의약품 마스터(제품·함량 목록) | 항목별 수정 방식 (`07` 4.4.1) | — | 오더에서 사용 중 | 판독 정확도 측정 방식 |

## 3. 데이터 카드 — 출처 · Key · 갱신 주기

### 3.1 DUR (심평원 점검 기준 · 식약처 공공 API)

심평원 DUR 점검은 **처방전 내**(병용금기 · 특정연령대금기 · 임부금기 · 안전성 사용중지 · 용량주의 · 투여기간주의 · 저함량 배수처방)와
**처방전 간**(병용금기 · 동일성분 중복 · 효능군 중복)으로 나뉜다.

| 데이터 | 쓰는 곳 | 출처 | 연결 Key | 갱신 주기 | MVP | 법무·계약 |
|---|---|---|---|---|---|---|
| **병용금기·병용주의** | 함께 복용 확인 | 식약처 DUR 품목정보 API `getUsjntTabooInfoList` | 성분코드 쌍 · 품목기준코드 쌍 | 고시 개정 시 (연 수회) | **필요** | 고객앱 노출 가능 여부 |

## 4. 내부 검증에 필요한 데이터
