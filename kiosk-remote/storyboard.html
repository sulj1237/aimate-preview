키오스크 원격지원 · 화면설계서 (스토리보드)

상담원이 슈퍼어드민에서 6자리 코드를 받아 약사님께 불러 주고, 약사님이 키오스크에 입력하면 원격으로 연결된다. 화면 번호 = 오른쪽 데이터 정의 번호.

💡 진입 슈퍼어드민 › 약국관리 › 약국 관리 › 약국 상세 › 태블릿 정보 · 코드 화면은 약국 상세 위 모달, 연결 후 키오스크 화면은 원격지원 창(새 창). 개발 규격 : 브루노 HP-1281(접속 정보 30초 · 1회용), 원격지원 주소는 배포 후 확정. 화면 데이터는 예시 값.
