키오스크 원격지원 화면 기획서

상담원이 슈퍼어드민에서 코드를 받아 약사님께 불러 주면, 약사님이 키오스크에 입력해 원격으로 연결됩니다.

작동 흐름

  1. ① 상담원키오스크 원격지원 클릭
  2. ② 새 창6자리 코드 발급
  3. ③ 상담원약사님께 코드 안내
  4. ④ 약사키오스크에 코드 입력
  5. ⑤ 원격 연결키오스크 화면을 보며 지원
  6. ⑥ 연결 종료상담원 [연결 종료] · 약사 [해제] · 30분 자동 해지

알아두기

  • 코드는 5분 동안 유효합니다.
  • 5분이 지나면 ‘입력 시간이 만료되었습니다.’ → [새 코드 받기]
  • 연결 30분이 지나면 자동으로 끊깁니다. 남은 시간은 원격지원 창에 보입니다.
  • 창을 닫거나 버튼을 다시 누르면 이전 코드는 못 씁니다.
