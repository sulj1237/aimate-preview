공통 기준

  • 상태 — 접수 → 처리중 → 처리완료 → 종료, 분기 추가 확인 필요 · 반려. 담당자 배정·이관은 상태가 아니라 이벤트로 기록한다.
  • 처리완료와 종료 — 처리완료 = 담당자가 조치를 마친 시점, 종료 = 접수자가 고객 안내까지 마친 시점.
  • 시간 기준 — 시작 = 접수일시(전화 받은 시각, 등록 시 기본값 현재 시각), 끝 = 종료 시각. 전화 연동(CTI)은 Phase 2에서 접수일시를 자동으로 채운다.
  • 반려와 이관 — 반려 = 접수 정보 부족으로 접수자에게 돌려보냄. 담당자를 잘못 배정한 경우는 이관(사유 오배정).
  • 기존 데이터 이관 — 접수요청 → 접수, 확인중 → 처리중, 처리완료 → 종료. 약국이 비어 있는 기존 건(`-`) 처리 방식 확인 필요
