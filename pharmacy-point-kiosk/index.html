약국 포인트 · 프로토타입

키오스크 5개 화면(첫 화면·약국 회원가입·굿팜 앱 바코드 인증·상품 목록·결제 완료)을 중심으로, 고객앱·POS 시안을 함께 검토합니다. 화면을 눌러 이동하세요. 실데이터 아님 · 적립·사용 규칙은 02 정책이 기준입니다.
키오스크 5개 화면은 실제 키오스크 디자인(1280×800 시안)의 색·치수·상단 바 구성을 따릅니다 — 보기 편하도록 60%로 줄여 보여 줍니다. 단계 표시는 결제 흐름이 시작 · 목록 · 결제 · 완료, 가입 흐름이 전화번호 · 이름 · 선택 정보 · 약관으로 각각 따로 갑니다.
약국 회원가입은 선택 정보(성별·생년월일)를 받으면 3화면(① 전화번호 → ② 이름 → ③ 선택 정보 · 약관), 받지 않으면 2화면(① 전화번호 → ② 이름 · 약관)입니다. 약관은 마지막 화면에 붙습니다. 폼을 2열로 눕혀 자판이 올라와도 약관과 가입 버튼이 가려지지 않습니다. 자판은 쿼티 두벌식(한/영 전환)입니다. ①에서는 취소, ②·③에서는 이전이 키패드 아래 주 버튼 왼편에 있고, 상단 왼쪽 ← 처음으로는 ②부터 나오고, 누르면 가입을 취소할지 묻는 모달이 먼저 뜹니다. 키오스크 설정은 약국 기기 설정이라 화면 밖(위쪽 버튼)에 뒀습니다 — 눌러서 화면 수가 바뀌는 걸 확인하세요.
성별·생년월일은 선택값이라 넣지 않아도 가입됩니다. 약사님 호출하기(키오스크 버튼 · POS 알림)와 전화번호 조회·본인 확인은 다음 배포에서 진행합니다.
POS(클라이언트 3.0)는 실제 클라이언트 화면 구성(고객정보 · 판매 목록 · 결제 목록 · 하단 합계)을 따릅니다. 상태 칩으로 고객 찾기 → 회원 없음 → 적립 여부 → 키오스크 가입 대기 → 가입 완료 흐름과 포인트 사용 · 사용 불가 모달을 확인하세요. 키오스크에서 인증을 마치면 상단에 가운데를 가린 이름(김*수 님)으로 표기합니다 — 앱 회원이 아니어도 같습니다. 생년월일·성별 수집 여부는 키오스크 설정에서 조정합니다(③ 화면의 설정 버튼으로 확인). 입력 방식 비교: 한 화면 입력 vs 단계별 입력 보기 ›
